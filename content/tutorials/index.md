Step-by-step tutorials, each built around a real event. Read them in this order; each one builds on the previous:

1. [[Basic Plotting Workflow]]: find products, plot them, navigate in time. No code.
2. [[Catalogs]]: mark events, browse and share them.
3. [[plot templates]]: save a panel as a template, then script it from a notebook.
4. [[virtual products]]: compute your own product in Python and plot it like any other.
5. [[Batch quick-looks]]: run a script without the window, to make plots in bulk.

Then pick the [user guides](/guides/) you need, and keep the [[Python API]] reference at hand.
